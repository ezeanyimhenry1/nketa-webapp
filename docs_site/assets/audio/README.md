# Benchmark audio clips

These WAV files are copied from `benchmark/audio/` during the docs build.

| Prefix | Description |
|--------|-------------|
| `local_name_*` | Igbo names (Intron TTS bootstrap) |
| `local_cs_*` | Code-switched phrases (Intron TTS bootstrap) |
| `afriswitch_*` | In-the-wild human speech from [AfriSwitch](https://huggingface.co/datasets/intronhealth/AfriSwitch) (CC BY-NC-SA 4.0) |

Regenerate: `python3 scripts/build_docs.py`
